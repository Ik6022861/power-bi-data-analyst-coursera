# Sorting and Filtering a Report in Power BI

## Overview

This project demonstrates how to **sort and filter data in a Power BI report** to help stakeholders explore marketing data more effectively.

The activity focuses on improving report navigation and usability by applying **sorting and filtering techniques** to different visuals such as ribbon charts, line charts, stacked column charts, and tables.

These techniques allow decision-makers to **quickly analyze relevant data and make informed business decisions**.

---

# Business Scenario

You are working as a **Data Analyst at Adventure Works**. The marketing team has provided a report containing data about marketing campaigns, leads, and order statuses.

Your task is to refine the report so stakeholders can easily analyze:

* Marketing performance by region
* Lead generation trends
* Social media performance
* Orders that have been successfully shipped

To accomplish this, you apply **sorting and filtering** to several visuals in the report.

---

# Objectives

The main tasks completed in this activity include:

* Sorting visuals for better data readability

# Visualizations Used

The report contains the following Power BI visuals:

* Ribbon Chart
* Stacked Column Chart

All visuals were adjusted using sorting and filtering techniques.

# Steps Performed

## 1. Open the Report

The existing marketing report was opened in **Power BI Desktop**.

Steps:

* Go to **File**
* Select **Open Report**
* Open the provided `.pbix` file

---

# 2. Sort the Ribbon Chart Chronologically

The ribbon chart was sorted by **Month** to ensure data is displayed in chronological order.

Steps:

1. Select the ribbon chart
2. Click the **three dots (More options)** on the visual
3. Choose **Sort axis**
4. Select **Month**
5. Choose **Sort ascending**

This allows users to view trends over time in the correct sequence.

---

# 3. Filter Ribbon Chart and Table for Shipped Orders

To analyze only completed transactions, filters were applied to show **Shipped orders only**.

Steps:

1. Select the visual
2. Open the **Filters pane**
3. Drag **Order Status** into **Filters on this visual**
4. Select **Shipped**

This filter was applied to:

* Ribbon Chart
* Table Visualization

---

# 4. Sort the Line Chart by Number of Leads

The line chart was sorted to show lead generation in **ascending order**.

Steps:

1. Select the line chart
2. Click **More options (three dots)**
3. Select **Sort axis**
4. Choose **Sum of No of Leads**
5. Select **Sort ascending**

---

# 5. Sort Table and Stacked Column Chart by Region

To organize geographic marketing performance, visuals were sorted by **Region**.

Steps for Stacked Column Chart:

1. Select the chart
2. Click **More options**
3. Choose **Sort axis**
4. Select **Region**
5. Choose **Sort ascending**

Steps for Table:

1. Click the **Product Region column**
2. Ensure the **arrow points upward** (ascending order)

---

# 6. Filter Stacked Column and Line Charts for Facebook and Google

To focus on the most important social platforms, filters were applied to show only **Facebook and Google leads**.

Steps:

1. Select the visual
2. Open **Filters pane**
3. Drag **Social Media** field into **Filters on this visual**
4. Select:

   * Facebook
   * Google

This filter was applied to:

* Stacked Column Chart
* Line Chart

---

# 7. Filter Table for Facebook and Google

The same filter was applied to the **table visualization**.

Steps:

1. Select the table visual
2. Open the **Filters pane**
3. Drag **Social Media** field
4. Select **Facebook and Google**

This ensures consistent analysis across visuals.

---

# 8. Save the Report

After completing all sorting and filtering tasks, the report was saved for future use.

Steps:

* Go to **File**
* Click **Save**
