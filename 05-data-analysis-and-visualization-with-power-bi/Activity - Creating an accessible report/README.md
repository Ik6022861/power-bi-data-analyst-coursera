# Designing Accessible Reports in Power BI

## Overview

This project focuses on **designing accessible and inclusive reports using Microsoft Power BI**. Accessibility ensures that reports can be used by a wide range of users, including people with visual, motor, or cognitive disabilities.

By applying accessibility best practices, data analysts can create reports that are **easy to understand, navigate, and interact with for all users**.

---

# Why Accessibility Matters

Data reports are often used by many stakeholders across an organization. However, not all users interact with reports in the same way. Some users may rely on **assistive technologies** such as screen readers or keyboard navigation.

Designing accessible reports helps:

* Improve usability for everyone
* Support users with disabilities
* Ensure compliance with accessibility standards
* Provide a better overall user experience

---

# Accessibility Features in Power BI

This project explores accessibility features available in Microsoft Power BI that help make reports inclusive.

### Key Features

#### 1. Alt Text for Visuals

Alt text provides a **text description of visuals** so screen readers can explain charts to users with visual impairments.

Example:

> "Bar chart showing monthly sales growth from January to March."

---

#### 2. Keyboard Navigation

Power BI allows users to **navigate reports using a keyboard** instead of a mouse.

This helps users who have difficulty using a mouse.

---

#### 3. Color Accessibility

Some users may have **color vision deficiencies** (color blindness).

Best practices include:

* Using high contrast colors
* Avoiding relying only on color to communicate information
* Using patterns or labels when needed

---

#### 4. Logical Reading Order

Visuals should be arranged in a **logical order** so screen readers can read the report in a meaningful sequence.

This can be managed using the **Selection Pane** in Power BI.

---

#### 5. Clear Titles and Labels

Charts and visuals should include:

* Descriptive titles
* Proper axis labels
* Clear legends

This helps all users quickly understand the data.

---

# Accessibility Guidelines and Standards

Accessible report design is guided by international web accessibility standards such as **Web Content Accessibility Guidelines (WCAG)**.

These guidelines are maintained by the
World Wide Web Consortium through the Web Accessibility Initiative.

They provide recommendations to make digital content usable for people with disabilities.

---

# Assistive Technologies

Assistive technologies help users interact with digital content.

Examples include:

* Screen readers
* Keyboard navigation tools
* Magnification software
* Voice control tools

Accessible reports ensure compatibility with these technologies.
