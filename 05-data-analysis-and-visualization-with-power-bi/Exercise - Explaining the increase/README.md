Explaining the Increase – Power BI Analysis
Project Overview

This project analyzes unexpected spikes in sales using Microsoft Power BI. The goal was to investigate sudden increases in sales totals and identify the factors contributing to these increases using the Analyze feature and clustering techniques.

The analysis was performed using the Adventure Works Sales Report dataset.

----------------------------------------------------------------------------------------

Dataset

File Used:
Adventure Works Sales Report.pbix

The dataset contains sales information including:

Order Date

Order Total

Product Name

Product Category

Product Price

Product Size

Payment Method

Location

These attributes were used to identify patterns and factors responsible for sales spikes.

----------------------------------------------------------------------------------------

Objectives

The main objectives of this exercise were:

Identify unusual spikes in sales.

Use clustering to group similar products.

Use the Analyze → Explain the Increase feature in Power BI.

Identify the key drivers behind sales growth.

Create additional visualizations to present insights.

----------------------------------------------------------------------------------------

Tools Used

Microsoft Power BI Desktop

Analyze Feature

Clustering Technique

Data Visualization

----------------------------------------------------------------------------------------

Steps Performed
1. Data Exploration

The dataset was first explored in Data View to understand the available fields.

Important columns identified:

Order Date

Order Total

Product Name

The Product Name column was selected for clustering because it has high cardinality (many unique values).

----------------------------------------------------------------------------------------

2. Identifying Sales Spikes

A Line Chart was created with:

X-axis: Order Date

Y-axis: Sum of Order Total

This visualization helped identify two major sales spikes:

March 3

March 7

These dates were selected for further investigation.

----------------------------------------------------------------------------------------

3. Applying Clustering

A Scatter Chart was created using:

Values: Product Name

X-axis: Order Total

Y-axis: Product Price

Clustering was applied using:

Automatically Find Clusters

Number of clusters selected: 3

Clusters helped group similar products and improve the insights generated by the Analyze feature.

----------------------------------------------------------------------------------------

4. Using the Analyze Feature

The Explain the Increase feature was applied to the line chart on:

March 7

March 3

Power BI automatically generated visualizations explaining possible causes of the sales spikes.

Key influencing factors identified:

Product Size

Product Category

Product Cluster

Payment Method

Location

----------------------------------------------------------------------------------------

5. Creating Additional Visualizations

Based on the insights, additional visuals were added to the report.

Donut Chart

Shows Order Total by Product Size.

Reason:
Product Size had only 2 values, making a donut chart suitable.

----------------------------------------------------------------------------------------

Treemap

Shows Order Total by Product Cluster.

Reason:
Clusters grouped products into 3 meaningful segments, making comparison easier.

----------------------------------------------------------------------------------------

Ribbon Chart

Shows Order Total by Product Category, highlighting which categories contributed most to the increase.

----------------------------------------------------------------------------------------

Key Insights

The main drivers behind the sales spikes were:

Product Category

Product Size

Product Cluster

These factors consistently appeared in the Analyze feature’s insights for both spike dates.

----------------------------------------------------------------------------------------

Final Report Visualizations

The final Power BI report includes:

Line Chart (Sales Trend)

Clustered Scatter Chart

Donut Chart (Product Size)

Treemap (Product Clusters)

Ribbon Chart (Product Category)

These visualizations collectively explain the reasons behind the sudden increase in sales.

----------------------------------------------------------------------------------------

Conclusion

Using Power BI’s Analyze feature and clustering techniques, the report successfully identified the key drivers behind unexpected sales spikes. The insights generated from this analysis can help the management team make informed decisions to sustain and improve sales performance.
